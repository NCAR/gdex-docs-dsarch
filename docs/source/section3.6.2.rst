3.6.2 - Increment Cache Number
=====================


.. _UC:

Action Option -**UC** (-**UpdateCache**) (Alias: -**UpdateCacheNumber**) :
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

increments the cache control
  number by 1 for the specified dataset, signalling that cached web content
  should be refreshed.
